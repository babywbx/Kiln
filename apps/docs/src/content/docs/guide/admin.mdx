Kiln 自带一套单页管理界面，随二进制一起分发，不需要额外部署。它覆盖日常运维的全部动作：配置频道、导入导出播放列表、管理节目单源、编排出站代理、签发播放密钥与 API Token、查看访问记录。

## 进入控制台

控制台挂在 `/admin` 下，根路径收到浏览器请求时会重定向过去。用配置里的账户登录，只有 `role = "admin"` 的账户能进入，其它角色会被退回登录页。

- **保持登录状态**决定令牌存在浏览器的哪一层：勾选写入长期存储，不勾选则只在当前标签页有效。同一浏览器的多个标签页共享登录态，任意一个退出，其余标签页同步退出。
- 右上角可以切换明暗主题，账户菜单里可以切换界面语言（简体中文、繁体中文、English），选择保存在本地浏览器。
- 左侧导航可以收起为图标条；表单有未保存改动时切换页面会先确认。

导航固定六个区：总览、频道、节目单、访问控制、网络出口、系统设置。

## 总览

进门第一屏，回答「现在是否正常」。

顶部是五个指标：频道总数、已启用频道、活动会话、节目单覆盖（已匹配 / 已启用）、已载入节目数。

「实例健康」展示 HTTP 服务可达性、Goroutine 数量和上次状态刷新时间，每秒自动刷新一次；服务失联时状态点会变红并持续重试。

「活动会话」列出正在运行的播放会话，每行给出频道、状态、类型、所用引擎、打包模式与最近一次错误，右侧可以直接停止某个会话。停止是即时的，正在观看的播放器会中断，下次有人播放时会重新拉起。

## 频道

频道区是控制台的主体，分列表页和详情页两层。详细的字段语义见 [频道管理](/guide/channels/)。

### 列表页

表格按频道、节目源、格式、运行方式、节目单、状态六列展示，行内提供预览与配置入口，并可上下移动调整目录顺序（顺序会影响播放列表的排列）。

页头的批量动作：

- **全部启用 / 全部停用**：停用会把频道从目录中隐藏并中断现有会话，播放地址随即失效。
- **导入 M3U / 导出 M3U**：见下一节。

### 详情页

详情页是一份分段表单，按顺序填写：

<Steps>
  <Step title="频道信息">
    频道 ID、名称与分组。ID 创建后不可更改。
  </Step>
  <Step title="节目源">
    完整的 HLS 或 DASH 源地址，并可当场测试当前地址是否可用、经由哪条出口连上。
  </Step>
  <Step title="运行方式">
    流媒体格式、启动时机（启动时预热、始终运行、有观众时启动）、无观众后停止的秒数、首选视频高度、最大观看人数等播放偏好。DASH 频道还可以在这里选择封装引擎，并用「智能识别画质与语言」读取 MPD，逐条列出可用的画质、音轨与字幕，确认它们能一起输出后再保存选择。
  </Step>
  <Step title="节目单与台标">
    指定这个频道在 XMLTV 中的标识。可以从已刷新的节目单里挑选候选 ID，也可以选择台标；台标留空时自动走 Kiln 的台标代理。
  </Step>
</Steps>

「高级请求设置」折叠区里是 User-Agent、附加请求头与故障恢复策略；敏感请求头保存后不再回显。「网络出口」可以让这个频道跟随全局规则、固定直连或固定走某个代理，也支持直接粘贴一条新代理地址快速创建。

页面顶部的命令栏提供四个即时动作：检查节目源、立即启动、打开预览、停止当前会话。底部的「频道管理」区收纳启用、停用与永久删除。

## 搜索与拼音粤拼检索

频道列表的筛选框同时匹配名称、ID、分组和频道的检索别名，并且内置了汉字到拼音与粤拼的映射：可以直接输入汉字，也可以输入全拼、首字母缩写或粤拼，简繁体互相通用。输入较长时还会容忍两个字符以内的拼写误差，输错一两个字母仍能命中。

映射表是按需加载的，第一次使用筛选时才会拉取，不影响首屏。

## M3U 导入与导出

**导入**接受粘贴的 M3U 文本，先解析出预览：逐条标出将新增、更新还是跳过，确认后才写入。导入是增量的，列表里缺失的频道不会被删除。

**导出**生成一份可以直接交给播放器的 M3U。导出时会自动创建一枚仅限播放、可随时吊销的分发凭据，因此导出的地址不会暴露管理员登录令牌。

## 节目单

「节目单源」表格管理所有 XMLTV 源。内置预设源默认全部停用，可以按需启用、编辑或删除，也可以添加自定义源，填写 `.xml` 或 `.xml.gz` 地址。每个源可以单独指定 ID、显示名称、时区和网络出口，访问受限时给它挑一个代理即可。

启用之后点「立即刷新」下载数据。刷新完成会给出载入的节目条数与失败的源数量，表格里同时展示每个源的运行状态：等待首次刷新、下载失败、数据已过期或正常，以及各自的频道数与节目数。

下方的「频道匹配概览」按已匹配、待确认、未匹配三类统计。Kiln 不会替你确认同名频道对应哪个 ID，待确认与未匹配的频道需要回到频道详情页逐个指定。完整流程见 [节目单](/guide/epg/)。

## 网络出口

出口区决定 Kiln 拉取节目源时怎么连出去，采用「草稿 → 测试 → 应用」的流程：所有修改先进入草稿，必须完成一次成功的路由测试，「应用更改」按钮才会解锁。

- **默认出口**：未命中任何规则的请求使用的连接方式，以及播放列表处理策略（全部经由 Kiln、保留源站地址、自动）。容器内需要访问宿主机代理时，在这里填容器代理主机。
- **代理服务器**：支持 `http`、`https`、`socks5` 与 `socks5h`。凭据只写入服务端，应用后不再回显。
- **路由规则**：按优先级排序，数字越小越先匹配，匹配类型包括主机名后缀、完整主机名、主机名正则、频道 ID 和完整地址正则。
- **连接测试**：既可以一键探测代理的公网连通性，也可以指定频道或自定义地址验证完整路由，最终返回 HTTP 200 才算通过。结果会说明实际走了哪条路由、经由哪个出口、耗时多少。

策略与规则的取舍见 [出站代理](/guide/proxy/)。

## 访问控制

这一区有两个标签页。

**播放密钥**列出所有已签发的播放凭据，展示名称、密钥前缀、频道范围、到期时间与状态。创建时可以限定允许的频道、设定有效期，完整密钥只显示一次，同时给出可直接复制的播放列表地址。已签发的密钥可以吊销（立即失效，保留审计记录）或删除记录。

**播放访问日志**记录播放列表与播放入口的请求：时间、密钥前缀、请求路径、频道、状态码和客户端地址。路径中的密钥只保留前缀。日志最多保留 5000 条，并按系统设置里的天数自动清理，也可以手动清空，清空不可恢复。

播放密钥的分发方式见 [播放与分发](/guide/playback/)。

## 系统设置

设置页自上而下四张卡片。

**账户与语言**展示当前登录账户和界面语言，并提供修改入口。修改用户名或密码需要验证当前密码，保存后其他设备上的登录会话立即失效。

**管理员 API Token**是给脚本和自动化用的独立凭据：按用途勾选 `read`、`write`、`delete`、`refresh` 四项权限（也可以先套用权限模板再微调），设定有效期，生成后明文只显示一次，服务端只保存 SHA-256 摘要。已有的 Token 可以编辑、轮换或撤销。同一张卡片下方是调用审计，逐条展示最近的允许与拒绝记录。完整规则见 [鉴权与凭据](/guide/auth/)。

**播放地址与访问日志**里有两个即时生效的设置：对外的公开访问地址（用于生成播放与播放列表地址），以及访问日志保留天数（1 到 3650 天）。

**当前运行配置**是只读的：监听地址、播放鉴权是否开启、CORS 来源、允许的公开主机和服务版本。这些项目需要改配置文件并重启才会生效，见 [配置参考](/reference/config/)。
