Kiln is a self-hosted HLS and DASH channel gateway. Its native engine decrypts and remuxes DASH sources directly, with no ffmpeg required; channels pull on demand and are reclaimed when idle; playback, administration, and scripted access each use their own credentials. Deploy it as a single binary or a Docker image.

Install with one command:

```bash
curl -fsSL https://raw.githubusercontent.com/babywbx/kiln/main/install.sh | sh
```
